# Job Catalog

**899 curated job-search sources in 18 categories** — job boards, remote-first
platforms, stack-specific boards, startups, gamedev, AI & Data, regional boards
for Europe/US/Asia, plus niche and industry lists.

The same catalog is made for two readers:

- **for a human** — a searchable offline page and a readable Markdown index;
- **for a machine** — one JSON file plus flat JSON/JSONL indexes with a small schema.

Focus: Moldova / EU market, entry to middle level. Everything is public.

## Open it

| What | Where | How |
|---|---|---|
| Interactive catalog | [`catalog.html`](catalog.html) | download and double-click — works offline |
| Readable index | [`INDEX.md`](INDEX.md) | browse here on GitHub, by category and subcategory |
| Mind map | [`mindmap.md`](mindmap.md) | renders on GitHub; offline version: [`mindmap.html`](mindmap.html) |
| Raw data | [`data.json`](data.json) | 899 sources, source of truth |
| Machine index | [`index.json`](index.json) | counts, categories, per-subcategory source list |
| Flat index | [`index.jsonl`](index.jsonl) | one source per line, enriched |
| Format | [`schema.json`](schema.json) | plain description of every field |

`catalog.html` has search, filters by category, subcategory, country, region and
remote, collapsible categories and a counter. It contains all the data inside the
file, so it needs no internet.

## For AI agents

The catalog is plain JSON, no authentication, stable field names.

```
https://raw.githubusercontent.com/FindLyTen/job-catalog/main/data.json
```

Shape:

```json
{
  "cats":  [{ "id": "dev", "name": "Development", "color": "#3b82f6",
              "subs": [["remote", "Remote-first"]] }],
  "items": [{ "id": "himalayas", "name": "Himalayas",
              "url": "https://himalayas.app", "tags": ["remote", "world"],
              "cat": "dev", "sub": "remote" }]
}
```

- Use `index.jsonl` if you want a flat list: one source per line, already joined
  with category and subcategory names, plus display-only fields (`country`,
  `region`, `remote`, `view_sub`).
- Use `index.json` to get category/subcategory counts without scanning 899 lines.
- `schema.json` describes every field in plain words.
- `data.json` is the source of truth and never changes when views are rebuilt.

## How the views are made

Everything except `data.json` is generated by one script:

```
python3 tools/build_views.py
```

It reads `data.json`, writes `catalog.html`, `INDEX.md`, `mindmap.md`,
`mindmap.html`, `index.json`, `index.jsonl`, `schema.json`, validates the result
(all 899 URLs present, JSON parses, no personal data) and prints a summary.

View-only enrichment does **not** touch `data.json`:

- country added to display names where the source is tied to one country;
- 37 sources that had no subcategory in the source got one, marked with `?` in
  the page and `(view)` in the index;
- Product & PM and Support & CS got extra subcategories for readability;
- "General Job Boards" is split by region in the page only.

## Local app (optional)

`app/api.py` is a small Flask app that serves `data.json` and the views:

```
pip install flask
python app/api.py            # http://127.0.0.1:5056
```

Environment: `JOB_CATALOG_HOST`, `JOB_CATALOG_PORT`.

## Notes

- Adding a source: edit `data.json` (append to `items`), then rerun
  `python3 tools/build_views.py`.
- `vendor/mermaid.min.js` is the only third-party file; it makes the mind map work
  offline. Mermaid is MIT licensed.
- The catalog is a list of links. Availability of each site is not guaranteed;
  a link check report is kept outside this repository.
